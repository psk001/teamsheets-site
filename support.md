# Teamsheets support

- **Email:** [support.teamsheet@gmail.com](mailto:support.teamsheet@gmail.com). We aim to reply within 2 working days.
- **Include:** your Jira site URL, what you expected, what happened, and a screenshot if you can.
- **Privacy and data requests:** see [privacy policy](privacy).

## Common questions

**Where is my time stored?** As normal Jira worklogs, so it also shows in each issue's Work log tab.

**Who can see other people's time?** Set by a Jira admin under Teamsheets → Settings → Team tab.
Reports follow the same rule.

**Can people edit time after submitting?** Not from Teamsheets. Jira itself can't block edits, so if a
worklog changes after submission the app flags the change to the approver.

**Why is there no file export?** Teamsheets runs entirely on Atlassian, and the available download
methods would mean opening a public endpoint. Export will come once Atlassian provides a way that keeps
the app on Atlassian.
